Waffle Boot

Install waffle-boot on your OP-XY, or upgrade and recover an OP-XY or OP-1 Field that runs it, in your browser.

Nothing is sent to a server. The page talks to the unit over USB, and the unit checks every image itself before it writes.

            Write the installer file from the developer menu

            We will install waffle-boot using developer mode on your unit, similar to a custom OS install.

            Back up your files first. The OS has to be installed again afterward.

            1. On the unit, open MTP mode in the developer menu.
            2. Connect it to this computer with a USB cable.
            3. Press Send and pick the OP-XY.

            The file is checked here, sent, then read back from the unit and compared.

                1. Download waffle-install.ldr.
                2. On the unit, open MTP mode in the developer menu, and connect it to this computer with a USB cable.
                3. Copy the file to the unit, named os.ldr.
                4. On the unit, press these keys in order: 2 leaves MTP mode, 5 writes os.ldr, 2 goes back, 6 restarts. The installer starts.

                Already on waffle-boot? Use Upgrade / Recover instead.

                    If something goes wrong
                    • No port named OP-XY Recovery. The unit is not in the recovery menu, or the cable carries power only. Check the screen, then try another cable or port.
                    • Refused or Stopped. Nothing was written. The message says why.
                    • The connection dropped during a transfer. Nothing was written. Connect and write again.
                    • FAILED while writing the other slot. The unit still starts as before. Write again.
                    • Install: the installer file could not be sent. The message says why. Choose Download it and copy it yourself instead.
                    • Install: a check did not pass. Nothing was written. The Install step says what the unit starts now; save check.txt, which lists every check.
                    • Install: the trial failed. Nothing was kept: the unit starts the bootloader it had. Hold the key the unit names to try again, or leave it as it is.
                    • The unit does not start after a restart. Switch it off and on with no key held. If it still does not start, hold M4 (4 under the display) again: recovery is in every image.
