waffle-boot is a clean-room implementation, not a decompilation. Its code is written from scratch, from
public documentation and the project's own functional specification, and the repository holds no code or
data from the device's firmware. The specification is not part of this repository.

Never paste, attach or link vendor firmware, or anything disassembled or decompiled from it, anywhere in
the project: issues, pull requests, commit messages, comments or tests.

## Contributions

waffle-boot is not taking outside code contributions yet. Bug reports are welcome as issues; never paste,
attach or link private material in one. [`CONTRIBUTING.md`](../blob/main/CONTRIBUTING.md) says what will
apply to a change once contributions open.
